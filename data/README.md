# Dataset Information

## Download Instructions

Due to GitHub file size limits, datasets are not included in this repository.

### Method 1: Kaggle API
```bash
kaggle datasets download -d bouchentoufothman/airbnb-paris
unzip airbnb-paris.zip
```

### Method 2: Manual Download

Visit: https://www.kaggle.com/datasets/bouchentoufothman/airbnb-paris

## Dataset Details

- **listings.csv**: 64,424 Airbnb listings (~300 MB)
- **calendar.csv**: 365-day availability data (~800 MB)
- **reviews.csv**: Guest reviews (~100 MB)

Place downloaded files in `data/raw/` (this folder is git-ignored).
